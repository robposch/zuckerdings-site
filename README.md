# ZuckerDings website

Static site for the ZuckerDings iOS app: landing page, privacy policy, and support.
Served via GitHub Pages at https://zuckerdings.poschenrieder.io/

- `/` - landing page
- `/privacy/` - privacy policy (required by the App Store)
- `/support/` - support page (required by the App Store)

Plain static HTML + one stylesheet. No build step.
